The first release of **Lanework**: a desktop home for building software with AI coding agents. Your issues, your repository and your agents (Claude Code, Codex and OpenCode) live in one window, and a conductor can split a request across several agents that work in parallel.

## Highlights

**Agents, side by side**
- Chat with Claude Code, Codex and OpenCode from the same composer, each on its own CLI and your own subscription. Pick any model the CLI offers, with effort and permission per conversation.
- Sessions in the sidebar show which agents are working, waiting for you or done. Stop, pin, rename or open any of them in a terminal.
- Slash commands, `@` file references, image attachments, dictation, and `/clear` to start a conversation over.

**Conductors and orchestration**
- A conductor is a team lead with its own instructions and memory of the project. Ask it for something large and it proposes a plan of workers, each on the model you choose, in its own git worktree.
- Approve the plan, follow every worker live, review and merge their results. Runs survive a restart, and the conductor reports back what needs you.
- A Sessions panel beside a conductor's chat shows its branch, worktree, changes, commits, runs and the sessions it started.

**Your project**
- Issues on a board, as a cloud board you can share or a local one that stays on your machine.
- Files with a tree you can edit, Changes with diffs and image previews, and Commits with history, a commit dialog (description and co-authors) and Push.
- Pull requests and GitHub issues next to your work.
- A project switcher grouped by namespace, with running agents on each project.

**Handing work between agents**
- The Lanework MCP server gives every agent your board and its cards.
- A checkpoint hook saves where a task stands after each turn, so another agent (or another machine) can pick it up when one runs out of quota.

**Around the app**
- One dynamic island for what needs you: an agent asking a question, board notices, sign-in, harness updates and short confirmations.
- Light and dark themes, your own UI, content and code fonts, notifications and a power saver for idle agents.

## Install

1. Download `Lanework-0.1.0-arm64.dmg` below. It runs on Macs with Apple silicon (M1 or later).
2. Open it and drag Lanework into Applications. The app is signed and notarized by Apple.
3. Install at least one agent CLI (Claude Code, Codex or OpenCode) and sign in to it. Lanework uses the CLIs you already have.

To check the download: `shasum -a 256 Lanework-0.1.0-arm64.dmg` should match `Lanework-0.1.0-arm64.dmg.sha256`.

## Updates

Lanework checks for new releases on launch and every few hours, downloads them in the background and installs on the next quit. You can turn this off or check now in Settings → About.

## Known limitations

- macOS on Apple silicon only for now. Intel Macs, Windows and Linux are not built yet.
- Agents run through their own CLIs, so their usage limits and sign-in are theirs.
