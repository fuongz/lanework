## Added

- **Conductors get their own tools**: conductors and team leads now drive runs, memory and models through the `lanework_control` MCP server, which the app attaches to their conversations only (Claude Code and Codex) and never writes into your agent config. Plain sessions see only what they can use there: creating a conductor and listing models.
- **A lead waits without polling**: after starting a run, the lead ends its turn and Lanework wakes it with an update listing every task's status, instead of a shell loop that keeps checking.
- **`models_list`**: a conductor asks for the models it may name when it needs them, with its own workers and how each model fared in past runs. A conductor's first message is about 70% smaller (6,281 → 1,897 tokens).
- **Durations on tool calls**: every tool row in a chat shows how long it took, and a group of calls shows its total, ticking while it runs.
- **JSON in tool panels is highlighted and pretty-printed**: keys, strings, numbers and literals each get a colour.
- **Agents know their board from the start**: every conversation the app starts is told its project's board, so the agent no longer looks it up from the git remote or asks you.

## Changed

- **Board rules now come from the Lanework MCP server**, the same text from the cloud and the local board. A project's AGENTS.md only needs a short pointer: **Ready for agents** offers to swap the app's old, long board notes for it (only when they match word for word).
- **The local board answers like the cloud**: the same tool outputs, `toggle_item` returns just the changed box, and `review_card` says what to do next for the card's lane.
- **The conductor dialog is larger and taller**, and its sidebar no longer repeats the name and icon.
- **Tool rows are more compact**: a search reads "Searched" or "Fetched", and a shell loop names the program it really runs.
- The board contract is now the `@lanework/contracts` package (it replaces `@lanework/protocol`).

## Fixed

- Chats in the Preview's local mode use the local board instead of the cloud one.
- Loading skeletons use the same background as the screen they turn into, so nothing changes colour on load.
- Folding a file in Changes or History no longer leaves a blank band above it.
- The local board records when a card started and when it was done.
- A local project created from a folder is linked to that folder's git remote.
