## [0.10.0] - 2026-11-19

### Added

- **Agents search with Lanework Kit by default**: Claude Code, Codex and OpenCode get the `lanework-kit` MCP server, now running the bundled `lwk` (lanework-kit 0.3.0). Claude Code and Codex conversations are told to use it instead of `grep`, `find` and `cat`. A search respects `.gitignore`, caps its output and answers in about 4–40 ms.
- **Search engine (lwk)** in Settings → Power saver: Always running (the default), On demand (stops after 5 idle minutes) or Per search (nothing stays in memory).
- **Project avatars**: give a project an icon, an emoji or one or two letters on a solid or gradient colour, from the pencil on its avatar in Settings → Projects. The avatar is saved with the project, so every machine and teammate sees it. **Use default** goes back to the GitHub icon or the letter.
- **Attachments inline**: an attachment can sit in your message as a chip with a thumbnail or file icon, its name and size. Deleting the chip removes the attachment.
- **Sent attachments preview**: sent images show as thumbnails that open large, and files show their size.
- **Switch from the breadcrumb**: in Settings → Harness, the CLI's name opens a menu of Claude Code, Codex and OpenCode with their logos. In Settings → Projects, the project's name opens a menu of your projects.
- **"Powered by @lanework-dev/kit"** on Lanework Kit and Search engine (lwk), linking to the kit's repository in your browser.

### Changed

- **`find_files` ranks like ⌘P**: in a git repository it lists hidden files too, and orders results the way the app's quick open does.
- **A tidier Settings → Harness**:
  - Lanework MCP shows its sign-in state and buttons on the same row.
  - Codex's hook approval sits on **Save progress for the next agent**.
  - **Push unfinished code** is one choice: off, changed files, or changed and new files.
  - **Sync sessions to Lanework** (was Pull all projects) sits in the Lanework group.
  - The last checkpoint is a line under the page title.
- **lanework-kit is now "Lanework Kit"** in Settings → Harness.
- **Deprecated models are off by default** in the model picker; turn any back on in Settings → Models.
- **Resize handles show a grip** in their middle on hover, instead of lighting the whole line.
- On a project's settings page, the breadcrumb's project menu replaces **Applying settings for**.

### Removed

- The **Resuming** section and the hook file rows in Settings → Harness.
- The **Status** section on each CLI's page in Settings → Harness; the last checkpoint now shows under the page title.

### Fixed

- A conversation closed or stopped mid-turn no longer keeps showing as working in the chat, the sidebar or its tab.
- A Claude Code or Codex process that crashes or is killed mid-turn no longer leaves its last turn spinning.
- Settings no longer calls the installed Lanework app's MCP entries "another server" when seen from the Preview or a dev build.
