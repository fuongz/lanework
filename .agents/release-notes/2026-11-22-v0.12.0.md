## [0.12.0] - 2026-11-22

### Added

- **Edit files in Repository › Files**: a text file opens in an editor with find and replace, multiple cursors, bracket matching and line comments. ⌘S saves it to the worktree, ⌘⌥S saves every open file. A file changed on disk since you opened it is not overwritten, and files that are not UTF-8 text, or too large, are not saved.
- **Unsaved changes are kept safe**: a tab with unsaved edits is marked. Closing it, switching project or folder, leaving the screen or closing the window asks **Save**, **Don't Save** or **Cancel**.

### Changed

- **The Claude Code plugin moved**: install it with `/plugin marketplace add lanework-dev/plugins`. `/plugin marketplace add fuongz/lanework` no longer works.
- **OpenCode starts only when you use it**: opening the Model menu no longer starts OpenCode's background service (about 300 MB), which used to stay running even after Lanework quit. It starts when you begin a chat on OpenCode.

### Fixed

- The Lanework and lanework-kit switches in Settings are no longer locked by a server entry an old development build left behind; Lanework now takes that entry back, so agents use your board again.
