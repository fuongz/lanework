## [0.15.0] - 2026-11-25

### Added

- **Routines**: a project's new **Routines** page runs an agent prompt on a schedule: every day, every week, every hour, a cron expression or once, in the time zone you pick. Each run is a new Claude or Codex conversation, in the project's folder or in a fresh worktree that is kept when the agent changed something. A run that missed its time while the Mac slept still starts within the grace you set, and one that runs too long is stopped at its timeout. When the agent has nothing to report, the run ends quietly. Otherwise you get a notification (**Settings › Notifications › Routines**).
- **Self-paced routines**: with the **Loop** schedule, the agent decides when it runs next. It can ask for the next run in 5 minutes to 24 hours, or end the loop when the work it watches is done, which turns the routine off. Its reason shows under the run in **History**. When it says nothing, the routine waits the time you set.
- **What a routine costs**: **History** shows each run's tokens and estimated cost, and the routine shows its total for the last 7 days. The cost is Claude Code's estimate at API prices, not what a Claude subscription is billed. Codex runs show tokens only.
- **Autonomy per project**: **Settings › Agents › Autonomy** sets one level per project (**Ask**, **Recommended**, **Full** or **Overnight**). The level decides which permission an assigned agent starts in, whether its recommended decisions are approved for it, whether it commits locally, and whether it moves the card to review. Change a setting yourself and the level reads **Custom**.
- **Agent contribution on pull requests**: a pull request's **Summary** lists each of its files that an agent in this project edited, with the agent, the conversation, its card and **Open**.
- **Pull requests in the chat**: a link to one of the project's pull requests shows as a chip with its state, number and title, and a command that creates or shows one (`gh pr create`, `gh pr view`) gets a card with its checks. **This session's details** lists the session's pull requests. Each opens in the app's **Pull requests** view.

### Changed

- **Assign to agent opens a chat** instead of a terminal tab, with the same card prompt. When Claude or Codex does not trust the project's folder, you are asked first: **Trust and start**, **Start without trusting** or **Cancel**.
- An agent Lanework starts on its own (an assigned card, a routine run) in a folder its CLI does not trust starts in **Supervised**, whatever its settings say, so the repo's own files cannot steer an agent nobody is watching.
- An agent working an assigned card reads, moves, ticks and checkpoints its card without asking permission each time, even in **Supervised**. Every other tool still asks as its permission mode says.

### Fixed

- Claude's folder trust was read too loosely: a trusted parent folder, or the filesystem root, counted as trusting every folder below it, though Claude itself still asked. The nearest folder with a record now decides, and the root never counts.
- A permission request for a tool called with no arguments showed a bare `{}`. It now says "Called with no arguments."
