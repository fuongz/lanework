## [0.14.0] - 2026-11-25

### Added

- **Conductors talk to each other**: a conductor can message another conductor of the project, and a session a conductor started can message that conductor mid-task. Between two Claude conversations the message goes through Claude's own channel; otherwise Lanework delivers it, and a conversation that is busy reads it when its turn ends. The first message between two conversations asks you first (**Allow once**, **Always allow** or **Don't allow**), and a pair can send at most 20 messages an hour.
- **Messages between sessions, shown**: a message one Claude session sends another now appears in the receiver's chat as a group-chat bubble, with the sender's avatar and name, a **Bypass permissions** tag when the sender skips prompts, and **Open** to go to it. Before, these messages were hidden while the agent still acted on them. You get a desktop notification when you are not looking at that chat.
- **Readable SendMessage**: when an agent messages one of its sub-agents or another session, the tool row reads "Messaged …" with the message's title, and opens to the message as text.
- **Session details**: **This session's details** adds **Talking with** (the sessions it exchanged messages with), **Sub-agents** (each one, running or done, with **Open**) and, for a conversation that switched agents, **Thread**: each session with its agent and model, and a hover card with its turns, context, tokens and cost.
- **Titles for follow-ups**: a conductor's instructions to its sessions, and a run lead's to its workers, can carry a short title. The session's chat shows the title with the full text folded under it, and the table of contents lists it.
- **Read back what a handoff left out**: after you switch a conversation to another agent, the new agent can read any earlier turn the handoff could not carry, by its label, and does so only when your request needs it.
- **Older CLI warning**: when Claude Code, Codex or OpenCode is older than Lanework needs, **Settings › Harness** says so and lists what is missing, the island offers **Update**, and the chat shows a notice. It still runs; only the features that need the newer version are turned off.
- **Fold Sessions**: click the **Sessions** heading in the rail to fold the group. It stays folded across launches.

### Changed

- **Switching agents carries less, and remembers more**: switching back to an agent the conversation already used continues that agent's own earlier session (Claude and Codex), so it keeps its full history. Later switches carry only what is new and point to the rest.
- **Table of contents on the left**: the prompts' rail now sits on the chat's left edge. It also lists prompts from before a compaction, dimmer and marked; clicking one unfolds the chat to it.
- Reading back earlier turns, and messaging another conversation, no longer ask for permission each time.

### Fixed

- A conductor that had switched agents could no longer start sessions or use its memory ("Only a conductor's own conversation…").
- **Approve** failed on a plan whose request was longer than 30,000 characters.
- The island no longer offers **Allow** for a session a conductor manages, which failed with "Could not answer".
